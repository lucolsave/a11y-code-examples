Autocomplete with grouped suggestions

Instructions

This example shows an autocomplete list with grouped suggestions.

Key Implementation Notes

This example is based on the a11y autocomplete suggestions Codepen example. Check it out for more specific information on the aria-attributes used in this example. This is what's uniqe to grouped lists:

Creating accessible groupings was a bit tricky tbh. The example borrows heavily from WAI-ARIA Grouped Listbox pattern, with a few changes.
Here's what worked:

  • Use a separate <div> for each group with role="group".
  • Focus handling:
    • NVDA announces groups only if focus is:
      • on the element with role="listbox" (per APG), or
      • the input uses aria-activedescendant instead of the listbox (our approach).
    • We chose the input-based approach to let users keep typing.
  • Group heading <div> elements must have aria-hidden="true" for NVDA to announce the group names.
  • Group headings should not have the role="option"attribute.
  • Group announcements aren't supported on touch devices (iOS, Android), but overall accessibility is good.
